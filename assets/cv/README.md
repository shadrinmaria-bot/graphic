# CV

Two files, one per language. Exact names (lowercase, no spaces, so the
URL works on every host):

    maria-lan-cv-en.pdf
    maria-lan-cv-he.pdf

Drop them in this folder and they are live at

    marialandzn.com/assets/cv/maria-lan-cv-en.pdf
    marialandzn.com/assets/cv/maria-lan-cv-he.pdf

Both links sit side by side in the About section, so nobody has to
click twice to find out which languages exist.

Keep each one under about 2 MB. A PDF exported for print carries
300 dpi images nobody will ever see on screen: export for screen
instead, or the file arrives at 20 MB.
